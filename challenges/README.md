# Make It Pop — challenge kits

One folder per day of the 30-day UI challenge. Grab one and remix it:

```bash
npx degit tamara-sary/makeitpop/challenges/day-04 my-day-04-remix
cd my-day-04-remix && npm i && claude
```

Each kit has:
- the day's design as a small working app
- `CLAUDE.md` — brief, constraints and top crits, so Claude Code (or Cursor) starts with context
- `REMIX.md` — starter prompt + LinkedIn caption with credit
